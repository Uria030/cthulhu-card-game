# E13 工單 — 大廳 64 選 1 + AI 隊友自動組成(短期測試目標)

> **目標一句話**:Uria 在主畫面大廳從 64 位調查員任選一位當自己,選定後系統自動組出另外三位 AI 隊友,直接開局可玩。
> **定位**:測試模式(64 位多為草稿態,終審前先能玩);正式的「四席手動選人」仍屬 M5,本單不做。
> **規約**:照 AGENTS.md Gate;逐項勾;交件送守燈人 review。日期碼 26070503。

## A|資料通道

- [ ] **A1 玩家清單放行草稿**:`GET /api/play/investigators` 加 `includeDraft=true` 參數(比照 E1 `crossTest` 邊界慣例):回傳全部 64 位 preset+完成態標記(`is_completed`)欄。預設行為不變(只列 completed)。
- [ ] **A2 bootstrap 草稿放行沿用**:選中草稿位時,client 對 bootstrap 帶 `crossTest=true`(既有機制,確認 lobby→battle 的參數傳遞即可,server 不用改)。

## B|隊伍儲存升級

- [ ] **B1 party 儲存改 templateId**:`ug_selected_party` 從 rosterCode 陣列改為 templateId 陣列;讀取端雙軌相容(讀到 rosterCode 就經 AI_INVESTIGATOR_ROSTER 換 templateId),寫入端一律新格式。
- [ ] **B2 TestScenarioScreen 接泛用 profile**:AI 席位載入從「rosterCode→名冊」改為「templateId→`profileForTemplate()`」(E11 引擎已就緒,名冊四人自動優先走名冊)。驗收:任選 3 位草稿當 AI 隊友能開局。

## C|自動組隊演算法(核心,資料驅動不寫死名單)

- [ ] **C1 演算法**:玩家選定後,從其餘 63 位算補位三人。規則(依序滿足):
  1. **陣營多樣**:三位 AI 的偏重字母(dominant_letter)互不相同,且與玩家不同(湊不滿才放寬)。
  2. **角色互補**:至少一位「收割位」(感知 ≥4);至少一位「輸出位」(熟練 ∈ shooting/military/brawl/assassin,或牌組含必中傷害——用模板欄位可判者為準);第三位自由。
  3. **決定性 + 變化**:同輸入同結果(排序 + 穩定 tie-break);提供「換一組」按鈕 = tie-break 種子 +1 重算。
- [ ] **C2 純函式落 shared**:`autoComposeParty(playerTemplate, candidates, seed)` 進 `packages/shared`(之後 sim/交叉測試也能用同邏輯),不寫在 UI 層。

## D|大廳 UI

- [ ] **D1 選人面板擴容**:玩家「我」面板列 64 位(用 A1),按陣營字母分組顯示,含稱號+陣營+草稿標記;現有 completed-only 行為以參數切換。
- [ ] **D2 自動組隊呈現**:玩家選定即自動組隊,組隊名單書櫃即時顯示三位 AI 的名字/稱號/陣營;附「換一組」鈕(C1 規則 3)。
- [ ] **D3 開局串接**:從大廳出發到戰鬥板,四席(玩家+3 AI)照 B1/B2 載入。

## E|測試與交件

- [ ] **E1 演算法測試**(shared 測試檔):①陣營多樣規則 ②收割/輸出位保證 ③同 seed 決定性 ④seed+1 產生不同組 ⑤候選不足時的放寬路徑。
- [ ] **E2 client tsc + 全 shared 測試複跑**。
- [ ] **E3 smoke**:sim 用 autoComposeParty 選一組跑 1 種子全場(證明組出來的隊能玩)。
- [ ] **E4 Gate 交件**:handoff + 送守燈人 review。

## 驗收(Uria 實測)

正式站大廳 → 選任一位(含草稿)→ 自動出現三位 AI 隊友 → 換一組能換 → 出發開局能玩到底。
