## 風險與範圍外發現

- 本包沒有啟動 384 場正式長跑，只驗證工具鏈可跑。正式長跑應由守燈人/主流程用產出的 team table 執行。
- `blueprintFormedTurn` 目前在 JSON schema 中保留欄位但填 `null`；真正偵測「藍圖成形回合」需要再定義成形判準。
- `crossTest=true` 是玩家 play bootstrap 的只讀測試邊界。若 reviewer 認為草稿 preset 不該經 public play route 暴露，即使是顯式 query，也可退回改成 admin-only bootstrap route。
- `fetch-preset-investigators.mjs` 需要 admin token，只讀 `/api/admin/investigators`，不寫 DB。
