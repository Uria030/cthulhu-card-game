## 變更摘要

- `GET /api/play/investigators` 新增 `includeDraft=true`，預設仍只回 `is_completed=true`；帶參數時回傳 preset 草稿、`is_completed`、`is_preset`、正規化後的 `proficiency_ids`。
- 新增 shared 純函式 `autoComposeParty(player, candidates, seed)`，依陣營多樣性、採線索位、輸出位、同 seed 決定性與 seed+1 變化組 3 位 AI。
- `ug_selected_party` 改成 templateId 陣列；讀取端相容舊 rosterCode，寫入端只寫 templateId。
- 大廳改成 64 preset 玩家 picker，顯示草稿標記；選玩家後自動顯示 3 位 AI 隊友與「換一組」。
- Briefing / Battle bootstrap 對草稿玩家帶 `crossTest=true`；AI 隊友 bootstrap 也帶 `crossTest=true`，並由 `profileForTemplate()` 支援草稿 AI。
- `sim-slit-3ai.ts` 增加 `--auto-player` / `--party-seed` / `--auto-list`，可用同一 shared 演算法產生 smoke team。
