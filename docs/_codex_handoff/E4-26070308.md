# E4 handoff:XP 結算 + 長休息/整備模式

## 變更摘要

- 接通 `chapter_outcomes.rewards` 到 `ScenarioReward`:支援 `xp / talent_point / talentPoints / cohesion`,並把 outcome `flag_sets` 寫入 CampaignProgress。
- 隱藏調查加成只讀 `hidden_info.reward_params` 中明確的 XP 欄位,不因「有查到隱藏點」自創平衡數字。
- 新增整備期購卡純函式:計算 `starting_xp × Exceptional` 成本、擋書籍/遺跡升級版、特殊卡、獨特已擁有與 XP 不足,購買成功會扣 XP 並把 card definition id 加進跨章 deck。
- `buildGameFromBootstrap` 支援 `CampaignProgress`:有 carryover deck 時,下一場用跨章一般牌組重建,同時保留簽名卡/弱點。
- `/api/play/stages/:id/bootstrap` 增加唯讀 `upgrade_cards` 卡池,供整備畫面購買。
- TestScenarioScreen 結局畫面顯示戰役 XP/天賦點/凝聚力/下一章;進入整備畫面可購買升級卡,進度寫入 sessionStorage,下一次 bootstrap 會帶入 CampaignProgress。天賦樹入口保留 disabled,實際生效留 E5。
