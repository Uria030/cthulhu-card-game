# E5 天賦樹接入(M3)

## 變更摘要

- 在 `CampaignProgress` 加入 `talents` carryover:已解鎖節點、陣營投資等級、已選分支、屬性加成、被動效果快照、天賦卡 id/code。
- 新增整備期天賦 helper:
  - `canUnlockTalentNode` / `unlockTalentNode`:扣天賦點、檢查前置/等級順序/分支鎖、套屬性 boost、記錄被動快照、`talent_card` 節點可把卡定義加入跨章牌組。
  - `canAcquireCardByTalent`:依 s11 天賦等級表限制玩家卡獲取,並疊加 `talent_branch_lock`。
  - `canPurchasePreparationCard` / `purchasePreparationCard` 預設啟用天賦 gate。
- `buildGameFromBootstrap` 會讀 carryover 天賦:
  - 屬性 bonus 套進下一場八屬性。
  - HP/SAN 上限用 boosted constitution / willpower 計算。
  - `talentNodeIds` / `talentBranches` / `talentEffects` 掛進 `InvestigatorState` 供 UI/後續引擎觀察。
  - `talent_cards` 補入卡面查找,讓天賦卡能被 carryover deck 實例化。
- public `/api/play/stages/:id/bootstrap` 加回傳:
  - `talent_tree`:所選調查員陣營的一棵樹,含 branches/nodes/effects。
  - `talent_cards`:該陣營 `talent_card_code` 或 `talent_branch_lock` 相關卡面,含 effects。
- 前端整備模式新增天賦樹面板:
  - 顯示天賦點/已解鎖數。
  - 可點節點,直接走 shared helper 寫回 `CampaignProgress`。
  - 購買升級卡時顯示天賦等級/分支鎖原因。
