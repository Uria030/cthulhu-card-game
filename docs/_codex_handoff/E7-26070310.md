# E7 章節→戰役串連(M3)

## 變更摘要

- `CampaignProgress` 新增 `chapterResults`,記錄每章 outcome、`next_chapter_version`、完成 stage 與結算時間。
- `scenarioRewardFromOutcome` 現在會從 `chapter_outcomes` 帶出 `outcomeCode` / `nextChapterVersion`;`settleScenarioEnd` 會把它們寫入戰役進度並發出 `chapter_result_recorded` effect。
- 新增 `resolveCampaignStageAccess`:
  - 無進度時只開各 campaign 第一章。
  - 已完成章標 `completed`,未來章標 `locked`。
  - 若上一章 `next_chapter_version` 能匹配當章 stage code/name/id,只開匹配分歧 stage,其他同章 stage 標 `branch_not_selected`。
  - 若 DB 尚未有可匹配分歧 stage,回落到當章第一個 stage,不阻斷連打流程。
- 抽出 client 本地 `CampaignProgress` sessionStorage helper,讓戰鬥板、世界地圖、劇情提要頁共用同一份進度。
- 世界地圖會讀目前選取調查員的進度,標示「完成 / 下一章 / 分歧 / 未解鎖」並禁止點擊 locked stage。
- 劇情提要頁會顯示上一章結局與分歧版本,並擋住直接 URL 跳章。
- 結算/整備流程新增分歧版本顯示與「前往世界地圖」按鈕,支援第一章結算後接第二章。
- `/api/play/stages` 額外回傳 `chapter_code`,供前端 stage list 保留章節代碼。
