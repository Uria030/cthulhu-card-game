## 變更摘要

1. `effectsExecutor` 新增儲蓄型回合開始執行器:
   - 只處理 `is_talisman + break_timing=stockpile` 資產上的 `round_start` / 舊別名 `on_turn_start` 的 `gain_use`。
   - 以來源卡 ID 精確補該張法器，不再按場上順序誤補其他武器/消耗品。
   - `gain_use` 依 `break_charge_max`(或 ammo/uses)封頂，effect log 回報實際補回量。
   - 非 `gain_use` 的儲蓄回合開始效果會明確回報 unsupported；不讓本包範圍外的通用回合觸發繞過 ruleEngine 後處理。
2. 新格式的儲蓄型法器在打出時由 0 計量起算，之後由 shared `runTurnStartUpkeep` 透過 effectsExecutor 累積；單機戰鬥板與多人 server 的回合交接皆接同一管線。
3. 向後相容:現有 seed 的儲蓄法器只有 `stockpile_accumulation_rule` 文字，尚無結構化 `gain_use` effect。這類舊卡保留原本的滿充能進場，不會因本次部署變成不可用。
4. 補回歸:
   - 儲蓄法器只補自身、接受 trigger 別名、封頂。
   - 回合開始實際經 effectsExecutor 累積。
   - 已配置的儲蓄法器從 0 進場；未配置的舊卡維持滿充能。

## 自知風險與範圍外發現

- 本包不解析 `stockpile_accumulation_rule` 的自然語言。能自動累積的卡必須以既有 `card_effects` 寫出 `round_start/on_turn_start + gain_use`；這符合 h03 的結構化效果合約。
