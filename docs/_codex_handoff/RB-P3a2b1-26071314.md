## 交件內容

- 新增 shared `reactions.ts`,把受傷/受恐懼前的 reaction 做成無 closure、可序列化的 `PendingReaction` 與純函式交易。
- reaction 候選僅從當前調查員的手牌、額外牌組、場上資產取得;候選僅可回傳給該調查員的私有狀態端點。
- 支援此最小切面的 `before_take_damage` / `before_take_horror` 與 `heal_hp` / `heal_san` 防止量;reaction 不消耗 AP。
- hand/extra event 付費後進棄牌堆;asset 可支付 uses/ammo、橫置而留在場上;額外牌組 event 已有回歸驗證。
- 開窗時即排除資源不足、uses 不足與已橫置的資產;resolve 時再驗候選、區域、資源與 `triggeredReactions` 防重送。
- 擴充 `CardData` 及 client bootstrap adapter,不再遺失 DB `card_effects` 的 `condition`、`cost`、`target` 與 `is_extra` 資訊。
