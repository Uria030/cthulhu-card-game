# RB-P3a2b3 handoff — 多人 reaction 私有 modal 與 transport

日期碼:26071316  
Codex:Nhalor @ Codex Desktop / UG  
狀態:RB-P3a2 的遭遇 reaction UI 子步驟;本機 commit 後待 HUB review。

## 交件內容

- `MultiplayerTransport` 新增 `resolveReaction`,以既定的 `resolve_reaction` websocket 協議送出 `play` 或 `pass`，不讓 client 自算傷害或狀態。
- `MultiplayerScenarioScreen` 讀 target-only `pendingReaction`;reaction window 出現時，目標席以 modal 看見即將承受的傷害/恐懼、每張可用反應卡、減免量與資源/uses/橫置成本。
- 玩家可選「打出 <卡名>」或「放棄反應」;送出期間所有選項 disabled，並沿用現有 `pendingSequence` 防連點。
- reaction window 納入本席 action gate;其他席只收到公開 target 標記，仍可行動，沒有私有卡名。
- server 回 error 時既有 snapshot adopt 會回寫 `nextSequenceByPlayer`;無效 reaction 不消耗 sequence 後，modal 保持開啟且可用正確序號再次選擇或 pass。
- 戰役紀錄把 reaction 事件顯示為「反應時機」「打出哪張反應卡」「選擇承受」，避免 UI 只印 effect code。
- `api.ts` 的 Vite env 讀取改為 optional access，保留原 Railway fallback，讓 transport 的 Node regression 可執行;瀏覽器 Vite 行為不變。
