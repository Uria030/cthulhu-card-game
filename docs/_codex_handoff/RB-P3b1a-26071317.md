# RB-P3b1a handoff — 光源物件與視線規則核心

日期碼:26071317  
Codex:Nhalor @ Codex Desktop / UG

## 交件內容

- `ScenarioState.lightSources` 新增可序列化的場上光源物件：來源卡片實例、所在地點與照明半徑。欄位為 optional，既有存檔仍可載入為無光源。
- 新增 `lighting.ts`：光源以物件所在地點為中心，沿 `connectedTo` 以 BFS 計算半徑覆蓋；不因調查員移動而跟著移動。
- 夜間/黑暗不再因 `create_light` 被改寫成 `day`。`create_light` 建立或更新光源物件，`extinguish_light` 移除資產自己的光源；無來源的場景效果則移除指定地點的光源。
- 攻擊、閃避與調查員 AI 攻防估值統一改用 `visibilityModifierAtLocation`，因此同一份光源覆蓋會同時影響真人規則結算與 AI 選擇。
- 資產的 `execute_card_action` 會帶入 `sourceAssetId`，讓重複使用同一盞燈更新既有物件而非堆疊無主光源。
