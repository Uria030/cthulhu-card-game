## 交件內容

- 修正管理後台權威 `consume_effect` 格式與引擎的斷層：引擎現在同時接受後台 `{ effect_type, amount/status/layers, value }` 與早期測試 `{ effect_code, effect_params }`，在扣 AP/棄牌前正規化。
- `gain_ammo` / `gain_charges` 正規化為既有 `gain_use`；`value` 是品管數值，不再誤傳進效果執行器。
- consume 只允許 h06 的即時輔助方向：資源、補充使用次數、HP/SAN、抽牌、正面狀態、移除負面狀態。移動/攻擊/調查等基本動作與未知 effect 都在支付成本前駁回。
- `add_status` consume 強制指向自身且只接受正面狀態；`remove_status` 只接受負面狀態。`effectsExecutor.remove_status` 現在尊重 `layers`，可移除指定層數而非一律全清。
- Test Scenario 的「消耗」按鈕要求 `consume_enabled === true` 且有 `consume_effect`，與多人 private card view 的條件對齊。
