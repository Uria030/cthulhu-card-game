4. 多人即時 Log 改復用 cinematic 行，而非直接拼接 `effect.type`；server 送來的敘事與 AI 摘要再過同一閘門。
5. 單機與多人畫面直接顯示的 `HP/SAN/AP/DC` 已改成「生命／恐懼／行動點／檢定目標」。
6. 卡片良率檢驗所的 `[LAB]` diagnostic block 刻意不過正規化：它是 creator 回報用原始效果碼與 state 觀測，不是玩家敘事。一般戰役 Log 在實驗場仍會過閘。
