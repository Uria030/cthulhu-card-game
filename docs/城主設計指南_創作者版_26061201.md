# 城主設計指南(創作者版)

- **日期碼**:26061201
- **讀者**:未來為本遊戲創作戰役/關卡/怪物的設計者(不需要會寫程式)
- **核心訊息**:**你在建立一個關卡的卡池時,其實就是在寫這一關的「城主性格」。**
- **本檔性質**:導讀與整合。各主題的權威細節在「出處」欄的原始規範,本檔不取代它們。

---

## 一、一句話理解城主

城主不是一段寫死的電腦程式,而是**一位拿著你配好的牌組上桌的對手**。

引擎只有一套決策框架(看局勢評分、按劇情節奏出牌、避免單調)。城主在某一關
「像什麼樣的對手」,完全由**你餵給它的資料**決定:

```
城主的性格 = 劇情主軸(節奏骨架)
           × 神話卡池(它手上有什麼牌)
           × 怪物池+行為腳本(它的棋子怎麼打)
           × 你的劇本(情感曲線)
```

**所以:換資料 = 換人格,不用寫程式。**

## 二、四個性格來源(你能控制的旋鈕)

### 2.1 劇情主軸 — 節奏骨架

10 種劇情主軸,每種對應一套城主每回合的固定出招節奏(出處:
`keeper_ai_regulation_v0_2 §3`)。挑了主軸,就挑了城主的「職業」:

| 主軸 | 城主像什麼 |
|---|---|
| 多目標封印 | 多線施壓的調度者 |
| 儀式打斷 | 倒數計時的祭司(進度自動 +1,守衛圍堵,低語削智) |
| 守護陣地 | 波次指揮官(敵潮一波強過一波) |
| 保護目標 | 死咬目標的獵殺者 |
| 逃離求生 | 在你身後放火淹水的災難本身 |
| 追擊狙殺 | 跟你捉迷藏的獵物(痕跡有時效) |
| 真相揭露 | 詐術師(篡改線索、散假情報,幾乎不召怪) |
| 多階決戰 | 會變身的最終頭目 |
| 資源累積 | 攻擊你產出點的破壞者 |
| 抉擇分歧 | 在每個岔路口等你的命運 |

### 2.2 神話卡池 — 它手上的牌

每關綁 10-15 張神話卡,**全部攤開給玩家看**(open-hand,玩家「看得到威脅但擋
不完」)。城主每回合用行動點「選」牌打,不是抽牌。你配池子時控制的是:

- **類別配比**:召喚(A)/環境(B)/施壓(C)/敘事干擾(D)/狀態打擊(E)
  —— 全召喚 = 蠻力型城主;敘事干擾多 = 陰險型城主
- **每張卡的節制閥**:`reusable`(可重用)/`cooldown_rounds`(冷卻)/
  `max_uses_per_stage`(次數上限)/`action_cost`(費用)
- **強度標籤**(`intensity_tag` small/medium/large):引擎的戲劇曲線會用它守門
  ——關卡前段城主只打 small 氛圍卡,中段解禁 medium,高潮才全力。
  **所以你給的 small 卡決定了「這一關開場的氣味」**

(出處:`keeper_ai_regulation_v0_2 §1/§2/§4`、`keeper_ai_v0_decision_spec §4`)

### 2.3 怪物池+行為腳本 — 棋子的智商與風味

**家族決定打法風味**(出處:`s14_monster_design_part2 §1-2`):

| 家族 | 追擊偏好 | 風味 |
|---|---|---|
| 克蘇魯 | 追最近的 | 潮水壓迫,再生護甲 |
| 哈斯塔 | 追理智最低(巨頭反向**獵清醒者**) | 攻心,美麗即武器 |
| 奈亞 | 追線索最多 | 欺騙,隱蔽突襲 |
| 莎布 | 最近(群體共享仇恨) | 數量氾濫,母體增殖 |
| 伊格 | 追血最低 | 伏擊,毒,時間站在蛇那邊 |
| 猶格 | 追感知最低 | 幾何錯誤,抹除 |
| 克圖格亞 | 最近 | 火,直球快攻 |
| 凡人墮落者 | 追線索最多 | 議程網絡,世俗背叛 |

**位階決定出招智商**(出處:`s14 補充文件 #2`,「結構化隨機」哲學——玩家學得
會節奏,但讀招不保證安全):

| 位階 | 出招模式 | 玩家體感 |
|---|---|---|
| 雜兵 | 純隨機 | 烏合之眾 |
| 威脅 | 加權隨機 | 有慣用招的野獸 |
| 精英/頭目 | **條件觸發** | 會讀你狀態的獵手(你理智高它攻心、它重傷轉兇暴) |
| 頭目 | 階段化 | 試探 → 認真 → 暴怒的戲劇弧 |
| 巨頭 | 腳本鏈 | 多形態的天災 |
| 萬象 | 儀式序列 | 祂不在乎你(但必須留玩家介入機會) |

**組池子要功能互補**(出處:`s14_monster_design_part4 §4.2`):別全放對抗型。
標準組 = 對抗 60% + 議程 20% + 環境 20%。議程型怪「存在即推毀滅」,逼玩家
在 N 回合內處理——這就是時間壓力的來源。

### 2.4 你的劇本 — 情感曲線(最上層的導演意志)

引擎強制城主遵守**三層情感曲線**(出處:G1 交付書 Part3 劇本,Uria 親筆):

1. **鋪陳期**(幕一前段):只准氛圍卡。「世界開始不對勁」——海腥味、雨變大、一盞燈熄滅
2. **升壓期**(幕一後段):召喚與施壓解禁。「牠們注意到你了」
3. **高潮期**(幕二之後):全力。「潮水壓過來」

加上**避免單調**鐵則:城主不會連續兩回合打同類牌(企劃書第七章 G4 驗收項)。

劇本還教了兩件事,寫卡時要記得:
- **登場要分拍**:裂嘴女登場 = 先聽聲(「我…漂亮嗎?」)→ 見人 → 揭真相,
  效果不准擠在同一瞬間
- **戰術呼應**:怪物招式施加的狀態要和玩家卡互動成 combo(裂嘴女噴黏液上
  「潮濕」↔ 玩家卡對潮濕目標雙倍傷害),玩家才會感覺「這關是有設計的」

## 三、實作對照(設計欄位 → 引擎行為)

| 你在後台填的 | 引擎拿去做什麼 |
|---|---|
| 神話卡 `card_category` + `intensity_tag` | 局勢評分(無怪→召喚優先/玩家理智低→攻心)+ 戲劇曲線守門 |
| 神話卡 `action_cost` / `reusable` / `cooldown_rounds` / `max_uses_per_stage` | 城主行動點預算(難度 1-5 = 每回合 2-6 點,可累積)與出牌節制 |
| 神話卡效果列(`action_code`) | 自動結算:推毀滅/召喚/恐懼/黑暗/全域檢定修正/附著狀態 |
| 怪物 `ai_preference` | 追誰(最近/血低/智低/**智高**/感知低) |
| 怪物 `move_pattern` + `behavior_script` | 出招智商(六模式;條件觸發 = 讀玩家狀態) |
| 怪物 `keywords` 含 `agenda_pusher` | 該怪每回合自動推 1 毀滅(存在即倒數) |
| 議程卡 `front_doom_threshold` | 毀滅壓力線(三張 ×4 = 12 點的失敗倒數) |
| 幕卡 `front_advance_condition` + `back_map_operations` | 玩家勝利路徑(集線索→切場景→生頭目→擊殺→結局) |

引擎現況(2026-06-12):上述全部已實作並有測試;`scripted_chain` / `ritual_sequence`
兩種巨頭模式與 narrative 詐術類神話卡(假線索/篡改/NPC)待後續引擎批次。

## 四、給創作者的設計檢查清單

建一個新關卡時,問自己:

1. **這一關的城主是誰?**(用一句話描述它的人格——「倒數計時的祭司」「咬住目標不放的獵殺者」)
2. 主軸選了嗎?神話卡池的類別配比呼應這個人格嗎?
3. small 強度的氛圍卡夠不夠?(開場的氣味靠它們)
4. 怪物池功能互補嗎?(全對抗型 = 無聊;有議程怪 = 有時間壓力)
5. 頭目有條件觸發腳本嗎?玩家能讀招嗎?讀懂之後有反制路徑嗎?
6. 怪物招式的狀態和玩家卡有沒有至少一組 combo 呼應?
7. 頭目登場分了幾拍?(一拍 = 沒讀懂劇本)
8. 三張議程翻完 = 怎樣的失敗結局?兩種結局的敘事都寫了嗎?
