# Part 2|遊戲本體工作包(Codex 寫碼 × 守燈人 review)

規約照 AGENTS.md 工程協作模式:附回歸測試、tsc 過、本機 commit 不 push、handoff 交件。每包標注規則書依據與驗收。**順位即建議施工序**。

### E1|遭遇卡觸發接線(M1 核心)
- **依據**:s09 藍圖;技術債文件 `docs/技術債_遭遇卡觸發系統`(五點清單,動工前先與現碼對賬——清單是 6/12 的)。
- **現況**:引擎 `encounters.ts`(draw/resolve/choose)已測綠;**client 零呼叫**;schema 缺觸發欄位。
- **範圍**:①四條觸發途徑接通(依技術債清單;含 encounter 神話卡途徑)②schema 觸發欄位 migration ③本體 UI:遭遇 Modal(敘事→選項→結算,沿用三段演出模式)④M1 範圍內每張遭遇走通用解,法器精細結算留 E3。
- **驗收**:實玩觸發到遭遇卡並完成結算;`encounters.test.ts` 擴觸發途徑案例;測試關卡池抽得到(技術債症狀自癒驗證)。
- **紅線**:多人一致性(遭遇效果打到全隊時走既有 updatedAllies 管線);冪等。

### E2|神話卡攤開選用(M1)
- **依據**:Uria 裁定 `project_keeper_mythos_open_hand`。
- **範圍**:①migration:mythos 卡 +reusable/cooldown_turns/max_uses ②`selectKeeperActivations` 改攤開池語意(冷卻/次數資料驅動過濾,戲劇曲線保留)③戰鬥板 UI:城主攤開池全可見+每張冷卻/剩餘狀態 ④城主 AI 選卡評分考慮冷卻機會成本。
- **驗收**:UI 看得到攤開池;冷卻/次數行為與資料一致;keeperAI 測試擴案例;sim 多種子回歸(勝負結構不崩)。
- **依賴**:D3 資料回填(migration 先行,回填隨後)。

### E3|法器三時機 + 過路費(M2)
- **依據**:s09(破除軸)+ s11-13;schema 12 欄已落地(MIGRATION_021/022)。
- **範圍**:法器 即時/檢定/儲蓄 三時機結算 + 過路費函數;與 E1 遭遇解鏈咬合。
- **驗收**:三時機各有測試;遭遇卡可用法器解(對照通用解成本差)。

### E4|XP 結算 + 長休息/整備模式(M3 起點)
- **依據**:ch4 成長系統;支柱 3 章節制。
- **範圍**:①過關 XP 結算(過關獎勵+隱藏調查加成)②章節間「整備模式」流程(本體新畫面:買升級卡/點天賦入口)③長休息語意(章節間恢復,區別於場內短休息)。
- **驗收**:打完一關 → 結算畫面看到 XP → 整備畫面能花掉 → 下一關帶著成長進場(接 CampaignProgress 跨章矩陣)。
- **依賴**:D5 升級卡池(引擎先行,池可後補)。

### E5|天賦樹接入(M3)
- **依據**:ch4;MIGRATION_031 talent_branch_lock + cards.ts 三端點已在;8 棵樹內容在庫。
- **範圍**:整備模式中點天賦 → 生效管線(天賦卡入牌組/被動掛角色);分支鎖規則。
- **驗收**:點一個節點,下一關實際生效(牌組或被動可觀察)。

### E6|玩家存檔層 3-2(M3,⚖ 擋在存檔歸屬裁定)
- **範圍**:依裁定(建議案:伺服器權威+輕量身份)實作;CampaignProgress 已就緒。**裁定未下前不接單。**

### E7|章節→戰役串連(M3)
- **範圍**:關卡結束 → 結局 flag → 下一章解鎖/分歧(flag 機制已有,缺流程與 UI:戰役地圖上的進度呈現)。

### E8|團隊精神接入(M3)

- **範圍**:組隊時選擇/生效管線(動工前先讀團隊精神設計文件定接入點)。

### E9|deferred 效果碼掃尾(M2)

- **範圍**:反應時機窗(對手行動時打出反應卡)、混沌袋操縱(look/manipulate)、tile 殘項、advance_act。動工前以 `effectsExecutor.ts` unsupported 清單+交叉測試的 `effect_unsupported` 報告為準。
- **驗收**:effectsExecutor 測試逐碼擴;unsupported 清單歸零或立債。

- **驗收**:守燈人拿它跑 384 場出報告。
