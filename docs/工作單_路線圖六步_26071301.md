## MP-N1|多人房間基建

**目標**:兩個 client 連同一房,狀態同步一致(不求可玩)。規格依 `M2M3規劃_26070505` Part 5 + R5。

1. **房間服務(server)**:房間生命週期 API+記憶體房態(開房→房間碼(6 碼易讀)→加入/離開→關房);身分 = E15 玩家 token;單房上限 4 席。
2. **權威引擎實例**:房內跑 shared 引擎(node 可跑已由 sim 實證);client 只送 intent、收「狀態快照+演出效果」;裁決沿用 `resolveIntent` 序列化——**多人一致性天然紅線:所有效果經 updatedAllies 模式廣播,禁止 client 自算**。
3. **WebSocket 通道**:連線/斷線偵測/心跳;斷線標記席位(接管邏輯留 N2);重送保護(intent 帶序號,重複序號冪等丟棄)。
4. **雙軌不互擾**:單機路徑(本機引擎)零改動;多人是新入口,feature flag 隔離,未開房時行為與現版完全一致。
- **不做**:選人流程/ready/斷線代打/UI 精修(全在 N2);觀戰/4 人(v2)。

**驗收**:整合測試——兩個模擬 client 同房各送 intent,雙方收到的狀態序列一致(含亂序/重送案例);單機全部既有測試零回歸;server 測試補房間生命週期案例。

**目標**:兩台裝置同房打完一關雨夜的真相 = 多人目標達成。

1. **開房流程**:大廳新入口(視覺沿用現有物件,佈局裁定照大廳盤點;R2:四座位=席位視覺——真人/AI/空位/ready 態)→ 房間碼邀請 → 各自 64 選 1(互斥鎖,server 裁決)→ 全員 ready → 房主開局;缺席 AI 補(沿用 E13 自動組隊)。
2. **宣告制結束(Uria 既裁)**:AP 歸零不自動結束(免費行動仍可用);每位明確按「結束行動」;AI 跑完整回合自動視為宣告;全員宣告 → 神話階段;UI 顯示未結束者;AP=0 且無可用免費行動時僅提示不代按。掛機逾時 = v2,不做。
3. **斷線代打**:斷線席 → AI 以該調查員繼續(同意圖管線,指揮層照常);重連 → 交還操作權 + 全量狀態快照重建畫面。

**驗收(= 路線圖目標②)**:兩台裝置(桌機+iPad)同房完整打完一關:選人互斥成立、宣告制推進正確、中途一台斷線 AI 代打 ≥1 回合、重連交還、結算各自入帳。守燈人 review 時加跑雙 client 整合測試。
