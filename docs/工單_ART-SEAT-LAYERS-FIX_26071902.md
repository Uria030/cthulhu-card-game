## Uria 兩條驗收大原則(全部工作只為這兩條)

1. **桌子永遠不被人影或影子蓋到**——桌面木紋在合成後必須完全乾淨。
2. **影子不可以看起來踩在桌上**——前景席的腳要落在地板上,有地板接觸感。

## 失敗現象(set-A/B 實查,代表性即可)

- 人影帶著「包一圈的均勻暗暈」,碰到桌面就把桌板罩髒(A 右緣地圖旁、左近角、B 右下書旁)。
- 前景席鞋底貼在桌腳/桌裙位置、腳下無地板影 → 讀成踩在桌上。
- 後席暗塊蓋過桌角 → 桌子與人的前後關係反了。

## 修正方向(圖層制)

1. **疊序**:底圖 → 後席人影 → 桌面前景層(逐像素取自底圖)→ 前席人影 → 前席地板陰影。
2. **桌面遮罩硬裁**:桌板做成遮罩;**所有人影與陰影的 alpha 進遮罩區一律歸零**(前席「本體」遮桌屬正常透視,不在此限;暗暈/羽化/陰影一律不准進)。
3. **陰影與人物拆層**:接觸陰影獨立成小層,只准落在地板/椅面,方向統一(背檯燈方向)。
4. **機械 Gate**:合成後桌面遮罩區與底圖逐像素 diff = 0(證明原則 1);前席鞋底落在地板帶(證明原則 2)。
