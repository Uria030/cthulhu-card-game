## 1. 判讀方法

本文件是 RB-P4c 的現況驗收表，不是規則書替代品。每一項以現行原始碼與可重跑測試判定，而非沿用舊文件的完成標記。

| 狀態 | 定義 |
|---|---|
| PASS | 已有可執行管線，且至少有對應測試；不代表每張資料庫內容卡都已製作完成。 |
| PARTIAL | 核心或資料模型已存在，但缺少規則書要求的子語意；必須引用一條正式債。 |
| DEBT | 尚未有可驗收 runtime 管線，或只停留在 schema、編輯器、內容規約。 |
| CONTENT | 屬資料庫內容、命名、平衡或創作規約；引擎不應假裝替內容驗收，列對應內容債。 |

## 7. P4c 結論與下一步

1. 引擎核心已不再是 26061301 的「大面積缺席」狀態。回合、死亡、檢定、混沌袋、戰鬥、盟友、狀態、光照、隱藏調查、五種任務、存檔與多人權威流程都有可重跑證據。
2. 規則書全兌現的剩餘工作不是把清單塗綠，而是處理 D-01 至 D-18 的明確容器、內容與驗證債。
3. RB-P4d 只負責 D-15 的統計基線，不可拿來掩蓋 D-01 至 D-14、D-16 至 D-18 的功能或內容缺口。
4. 最終路線圖驗收仍需要 Uria 實玩一場，確認玩家視角能體驗到本表的 PASS 系統；這是產品驗收，不由自動測試替代。
