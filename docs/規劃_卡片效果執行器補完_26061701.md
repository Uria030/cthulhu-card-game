# 規劃說明 — 卡片效果執行器補完(2026-06-17)

> 起因:playtest 發現「卡片打得出、效果不執行」。比對權威規格 vs 現況引擎,規劃補完範圍與批次。

## 一、權威規格(已讀)

**effect_code 詞彙**(產卡 Gemini 必從清單選):`admin-card-prompt.js` §5.5 + §九,**約 70 個效果動詞**。
**機制 + V 值**:規則書 `02_rulebook_ch2`(檢定/戰鬥/移動/資源/混沌袋)、`03_rulebook_ch3`(卡片/§6 狀態 21 種/§7 傷害·恐懼·治療 V 值:1HP=1V、1SAN=3V、治療 1.5V)、`s08–s10`(雙軸:殺敵軸武器 vs 怪 HP / 破事軸法器 vs 遭遇卡)、`s04`(V 刻度)。
**觸發類型**:`action`(打事件/用資產)、`passive`(常駐 modify_test)、`on_consume`、`on_play`、`reaction/on_take_damage`。

## 二、現況引擎

- **觸發路由「已通」**:`play_card`(事件 action→結算→棄,ruleEngine 1080)、`execute_card_action`(資產 action,1160)、`consume`(on_consume,457)、`passive`(passiveTestModifier)都已呼叫 `executeCardEffects`。→ **不是路由缺,是動詞沒實作。**
- **`effectsExecutor` 只實作 7 碼**:`draw_card / gain_resource / deal_damage / discover_clue / add_status / search_deck(簡化)/ remove_status`(另 `modify_test`/`attack` 走別處)。
- **其餘 ~60 碼 → `default → unsupported`**(no-op,只記 log `effect_unsupported`,不結算、不擋牌)。
- **狀態消費端已做**:`statusEffects.ts`(21 狀態回合結算/檢定影響)Phase 1 完成 → 用 `add_status`/`remove_status` 的卡可施加狀態;缺的是「其他系統動詞」。

## 四、改動計畫

1. **全補在 `effectsExecutor.ts`**:沿用現有 `switch` 架構逐碼加 `case`(純函式,吃狀態回新狀態 + `ResultEffect[]`);params 語意照 `admin-card-prompt §九`(如 `deal_damage {amount,element,direct?,area?}`)。
2. **觸發類型補洞**:`on_play`(資產進場效果)、`reaction/on_take_damage`(counterattack)目前沒路由 → 隨 P0 在 ruleEngine `play_card` 資產分支 + 受擊 hook 補上。
3. **目標選擇**:需選敵/選友的(transfer/move/stun)沿用現有「同地點 + area 旗標」規則。
4. **分批 + 每批驗收**:P0 → P1 → P2,每批補 `effectsExecutor.test`(逐碼結算測試)+ hub review + push。**P3 延後到 G4 地城**。
5. **狀態碼對齊**:對 `admin-card-prompt` 合法狀態清單(21 個)逐一確認 `statusEffects.ts` 都認得(別名收斂,沿用 normalizeStatusCode)。

## 五、風險/前提

- **效果分類 vs 動詞**:`counterattack/taunt/extra_attack` 是 effect_code(寫進 effects + trigger),不是關鍵字(prompt §853 明示)→ 要做對應 reaction/action 結算。
- **成長型 amount 語意**(prompt §954):`wild_attr_boost`/`transfer_horror` 的 `amount` = 卡片可達**最終最強狀態**,不是單位增量 → 結算要照此讀。
- **V 值不進引擎**:V 是產卡設計/驗證用,引擎只結算機制。
- **軸向 combo(AI 修正#2)是另一層**:那是「新增連動效果碼 + 同軸指認」,本批先把**既有單卡效果**補齊,連動 combo 效果屬後續設計(s08–s10 落地)。

## 六、建議起手

**P0 先做**(治療/恐懼/分擔/控場 ~10 碼)——這批讓「大部分非武器卡」從 no-op 變有效,對遊戲本體可玩性最關鍵。
