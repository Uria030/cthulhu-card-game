## 步 1|DESIGN-CONSTITUTION:憲法修訂(守燈人擬稿 → Uria 核;與工程並行)

1. 第一章 token 區大致保留;修訂對象是 Overview/色彩章的「暖調近黑白全域 5-15% 彩度上限」條款群——Uria 判定過頭、作廢。
2. **新彩度分層總原則**:背景、面板 = 低彩度(年代感、退位);主角(棋子/角色)、卡片 = 高彩度(一眼跳出)。
3. **新參考語彙**(用於角色/棋子/卡片/行動特效,**不強迫背景**,不把克蘇魯氣氛帶偏):1930-40 經典動畫(湯姆貓與傑利鼠)之配色/手繪賽璐璐/立體卡通標題字;打擊特效參考老電視蝙蝠俠誇張字卡語彙。
4. 質感:整體可帶老電視粗糙感,畫質不用太好;降精細度、往手繪樸拙走(現行素材太精細太雕刻)。
5. **同一 commit 內同步更新 Imagegen prompt 共同前綴模板**(舊 5-15% 上限刻在 VISUAL-REMAKE 各 prompt 裡,不同步改素材線仍生成舊風格)。
6. 無人像紅線、手作、44px 觸控等條款不動。**憲法定稿(Uria 核准)後 ART 線才開跑。**

## 步 2B|ENG-B AI-PARTY

## 常設裁定:棋子擺放(Uria 明定 26071202 §C.2,26071313 重申,任何規劃不得回退)

- 棋子 = **獨立 DOM 圖層**,站在**所屬地點卡的圖片區域內**;**嚴禁烤進卡圖素材**。
- 不佔用地點名稱、線索指示(固定卡片最下方)、操作按鈕區;多枚棋子有固定排列規則,不互相遮擋。
- 棋子是盤面主角層:高彩度、尺寸一眼可辨、無發光圈。
