## 0. 背景與問題定義

Terra 逐張生成的素材品質合格,但**組合到畫面上就不對**。根因有三:

1. 各素材沒有共同的「鏡頭/光源/色調/顆粒」合約,各自漂亮、彼此打架。
2. 7/12「暖調近黑白」裁定被執行成「全畫面降飽和壓暗」——裁定原意是**淡茶色亮調相紙**,不是炭黑暗房。
3. 部分素材語言用錯層(棋子放進大廳、棋子合成進卡圖、剪影做成純黑貼紙)。

本計畫五個工作項:**A 大廳底圖重生成、B 座位人影覆蓋層、C 64 職業棋子、D 固定介面尺寸合約、E 木質儀表板重製**。A/B/C 是 Terra 生成 + Nhalor 接線;D/E 是 Nhalor 工程為主、Terra 出殼素材。

## 1. 全素材共同色調母語(Terra 每一張圖的固定前綴)

Uria 給了兩張 1930 年代真實老照片作為色調標準(情侶與轎車 / 小徑上的女子)。量化成硬條款:

| 條款 | 規格 |
|---|---|
| 底色 | 象牙/奶油褐相紙底,整張像泡過淡茶;禁灰底、禁黑底 |
| 黑位 | 最暗處 = 深褐(約 `#2b221c` 量級),**全圖不得出現純黑色塊**;最暗處仍須可辨形體 |
| 亮部 | 乳白/淡黃(`world-aged-paper #E8DCC4` 量級),禁純白爆光 |
| 密度結構 | **中間調佔絕大多數**——雨夜、恐怖題材也一樣;陰沉靠題材(雨、霧、視線、留白),不靠降亮度 |
| 彩度 | 殘留 5–15%,「彩色照片褪到剩一口氣」,不是灰階套茶色濾鏡 |
| 質感 | 細銀鹽顆粒、輕微褪色不均、可用相紙邊;禁重污漬濾鏡 |
| 禁區 | 高飽和插畫感、卡通描邊、青橙調色、大片深紫黑、暗角遮內容 |

**Imagegen 固定前綴(每張素材 prompt 開頭原句照抄):**

```text
1930s archival photograph aesthetic, warm sepia-toned near-monochrome,
ivory/cream paper base tone, lifted blacks (deepest tone is dark brown,
never pure black), creamy off-white highlights (never pure white),
midtone-rich exposure like a well-lit vintage print, 5-15% residual
muted color, fine silver-halide film grain, subtle uneven fading.
NOT: dark moody render, NOT crushed shadows, NOT saturated illustration,
NOT teal-orange grading.
```

例外:C 棋子與 E 儀表板殼是「實體道具攝影」,同樣套此前綴,但主體本身允許漆色/黃銅的克制彩度(見各節)。

**驗收(每張圖三查):** ① 直方圖無純黑純白堆積 ② 縮圖 10% 仍辨識主要物件 ③ 憲法四道檢查(年代影像/陳舊/克制陰沉/手作)。

## 2. 工作項 A — 大廳底圖重生成(調查室 → 書房)

### 2.1 情感規格(最高優先,構圖服務這四條)

1. **這是「我的書房」**:我跟朋友聚在書桌前,討論等等要去哪冒險。是聚會,不是辦公。
2. **有溫度**:壁爐生著火(畫面唯一暖橘光源,右側)+ 桌上檯燈光池;不是均勻冷灰檔案室。
3. **窗 = 旅程預告**:後方大窗,窗外雨夜街景(路燈、馬車/行人剪影、濕反光)——天氣不好,暗示等等的冒險。
4. **紀念牆 = 帳號歷史**:側牆是紀念區,記載死去/退休調查員——**禁人臉肖像**(憲法 26071202),改用:黑紗綬帶木框內放**無人的地點舊照/證件文件/黃銅銘牌(可留刻名空位)**、下方小數據刻牌。

### 2.2 構圖規格

- **鏡頭**:第一人稱坐在書桌前的近景——桌面佔畫面下 1/3,視線微俯;禁止站在門口看全室的遠景(現行調查室的敗因之一)。單點透視,消失點在窗中央附近。
- **佈局**:中央大書桌;後方大窗(雨夜街景);右側壁爐(生火);左/右側牆紀念區;背景書櫃(入口之一)。
- **底圖必須無人**:空椅 4 張(桌後 2、左右各 1),人影走工作項 B 覆蓋層。椅面、椅背完整可見(B 要坐上去)。
- **桌上 8 件入口物件**,一字排開隨手可得,彼此不遮擋、各自留出可點擊的視覺分離(現行入口對位座標沿用,生成時按此相對位置擺):
  銀色天平(購買與強化)/ 黃銅香爐(團隊精神,微煙)/ 鐵砧與鎚(鍛造)/ 玻璃藥瓶群(卡片檢驗)/ 調查帳本(牌組)/ 封蠟文件(天賦點)/ 地圖紙(選關,半攤開)/ 研究厚書(研究升級)。
- 光:窗口冷灰漫光 + 檯燈暖光池罩住桌面物件 + 壁爐暖橘側光——三光源,方向要能被 B/C 素材繼承。

### 2.3 交付

- `game-art/lobby-v4/study-base.webp`,≥2400×1600,**webp q80–85、≤450KB**(L1 開機 preload,順帶解掉 PLAYTEST-BATCH3 WARN-2 的 2.34MB 問題)。
- Prompt = §1 前綴 + 2.1/2.2 敘述;先出 1 張校準,Uria 驗收後才鎖定。

## 3. 工作項 B — 座位人影覆蓋層(歷次失敗的正解)

### 3.1 失敗史(為什麼以前都不對)

- 純黑貼紙剪影:零光影互動、坐在書堆上、懸浮無接觸陰影(版本 A)。
- 烤死的真人全景:臉孔違憲、隊伍換人即作廢(版本 B——但它證明 Terra 融合能力達標)。
- 棋子上桌:把戰鬥盤面的單位語言搬進大廳,聚會感歸零(現行版)。

### 3.2 人影合約

| 條款 | 規格 |
|---|---|
| 資產形式 | 逐座位覆蓋層,透明底 webp,尺寸對齊該座位框 |
| 本體 | **背光暗褐人形剪影**(最深 `#2b221c` 量級,禁純黑),無臉、無手指細節 |
| 光影 | 邊緣 rim light 繼承底圖局部光源:靠窗座冷灰邊、靠火座暖橘邊、桌前座檯燈頂光;**必須有接觸陰影**(臀-椅、腳-地) |
| 姿勢 | 只准「坐在椅子上」,姿態放鬆(前傾聽講/靠背/交腿);禁坐桌面、禁站立 |
| 邊緣 | 2–3px 柔化,不透明度 80–90% |
| 職業辨識 | 只用四項:帽形 / 髮形輪廓 / 肩線(大衣/西裝/披肩)/ 坐姿。映射用既有 6 職業原型(archivist/craftsperson/healer/mystic/performer/watchman),與棋子同一原型資料 |
| 座位 | 4 席全部有人影(玩家席也有,對齊舊版正面範本);隊伍不足 4 人時該席留空椅 |

### 3.3 生成協定(鎖透視的關鍵,Terra 照做)

1. 從 A 底圖裁出該座位區塊(椅子 + 周邊 15% 邊界)。
2. 以該裁片為底做 inpaint/合成生成:「在這張椅子上加一個(原型)坐姿剪影」,同一句 §1 前綴 + 3.2 合約。
3. 產出後去背,只留人影 + 接觸陰影,存為該座位覆蓋層。
4. **每席每原型一張**:4 席 × 6 原型 = 24 張,`game-art/lobby-v4/seat-{1..4}-{archetype}.webp`,單張 ≤120KB。

### 3.4 Nhalor 接線

- 隊伍資料 → 席位 → `職業→原型` 映射(與棋子共用同一張映射表)→ 疊對應覆蓋層;換隊即換圖。
- 名字標籤放人影下方舊紙小牌(工作項 E 的字體合約適用),不再壓在人影身上。

## 4. 工作項 C — 64 職業棋子規範

### 4.1 母版配方(= Sol 版成功參數,逐條固化)

好版實證:`game-art/pawns/pawn-player.png`(暗紅漆木偵探胸像)。失敗版反例:`pawns/archetypes/*.png`(整顆均勻古銅金屬,丟進近黑地圖即隱形)。

| 條款 | 規格 |
|---|---|
| 形制 | 西洋棋式**胸像/立身棋子**,圓形車床底座(1–2 環線腳),雕刻木質 |
| 上色 | **全身玩家色陳年漆木**(啞光/緞面,禁鏡面金屬、禁塑膠光) |
| 稜線 | **所有雕刻稜線帶金色磨損描邊**(edge-wear gilding)——這是暗底圖上的可見性來源,必須全身覆蓋,不只帽緣 |
| 職業辨識 | 雕刻層做:帽形 / 服裝剪裁 / 1–2 件手持或佩掛道具 / 姿態。**不靠顏色辨識職業** |
| 鏡頭 | 正面微 3/4、視平線在棋子胸口高度、輕微俯角;64 顆同一鏡頭同一距離 |
| 光 | 左上主光 + 暖白 rim light 勾右緣;軟接觸陰影(橢圓,烤進圖或另片皆可,擇一全批一致) |
| 畫布 | 透明底,直式 2:3,人形佔高 82–88%;輸出 512×768 webp ≤150KB |
| 可見性驗收 | 縮到 **48px 高**貼在近黑地圖截圖上:輪廓可辨、四色可分、金邊可見——不過即重生 |

### 4.2 四玩家色(漆色檔案)

以憲法四玩家色為準(Sol 現行紫/正紅/金/青綠與憲法不一致,本計畫收斂到憲法;若 Uria 終審偏好保留 Sol 色相,只改此表不改配方):

| 檔位 | 漆色 | 錨值 |
|---|---|---|
| 玩家 1 | 赭紅 Russet | `#A04830` |
| 玩家 2 | 靛青 Indigo | `#3A4A78` |
| 玩家 3 | 苔綠 Moss | `#5A6E3A` |
| 玩家 4 | 赤金 Saffron | `#B07828` |

- 漆色允許彩度(它們是「上了漆的道具」,不受 §1 的 5–15% 彩度限制),但**明度中段**:漆色在陳年磨損下的整體明度不得低於中灰,避免靛青/苔綠沉入暗底圖(失敗版教訓)。
- 金色磨損描邊四色統一 `antique-brass #8B6F3D` 量級偏亮。

### 4.3 量產策略

- 64 職業(MOD-11 的 64 preset,職業名以 DB `title_zh` 為準)× 4 色 = 256 張。
- **每職業先生成赭紅母圖 → 同構圖重上色出其餘三色**(image-edit / recolor pass,不重擲構圖),保證同職業四色只差漆色。
- **Uria 裁定(2026-07-12)**:若程式變色/重上色管線困難,**准許 64 職業 × 4 色 = 256 張全部直接生成**;代價是同職業跨色構圖可能漂移,驗收時加抽「同職業四色並排比對」,漂移過大該職業重生。
- **校準輪先行**:先做 4 職業 × 4 色 = 16 張(建議取四陣營差異大的職業),過 4.1 可見性驗收 + Uria 點頭,才開 60 職業量產。
- 檔名:`game-art/pawns/v2/{career_code}-{p1|p2|p3|p4}.webp`。

### 4.4 使用層規則(Nhalor)

- 棋子只出現在**戰鬥盤面地圖層**(站在**所屬地點卡的圖片區域內**,永遠是獨立圖層;Uria 明定 26071202 §C.2,26071313 重申)與儀表板頭像窗。
- **禁止把棋子合成進地點卡圖內**(失敗版反例);禁止在大廳出現棋子(大廳是人影的層)。
- 大廳人影與棋子由**同一張 職業→原型/雕刻 映射表**驅動,換人同步換兩邊。

## 5. 工作項 D — 固定介面尺寸合約(Nhalor,layout/CSS)

**前提**:地圖層(地點卡+棋子)玩家可雙指縮放,**不入本合約**;合約只管不能縮放的固定介面。

| 條款 | 規格 |
|---|---|
| 總覆蓋率 | 固定介面合計 **≤ 25% 畫面**,其餘全留地圖視口 |
| 右欄(戰役紀錄) | ≤ 22%vw,每列 ≤ 8%vh |
| 左上資訊群(議程+幕) | ≤ 18%vw |
| 單一角落儀表板 | ≤ 13%vw × 12%vh |
| 底部 phase 控制列 | ≤ 5%vh |
| 佈局 | 全部貼邊角(下緣/側緣出血),窄長安靜;內容多時**面板內部捲動**,禁止向畫面中央長大 |
| 層級 | 固定介面永不遮蔽地點卡的預設落位;版面先保卡片軌道 |
| 縮放 | 介面大小設定(見 6.5)特大檔仍須守總覆蓋率,超出由內部捲動吸收 |

失敗基準(壞版實測):右欄 33%vw、資源板 27%×22%、議程框 28%vw——全部回收到上表。

## 6. 工作項 E — 木質儀表板重製(Terra 出殼 + Nhalor 活字)

> **⚠ 狀態(2026-07-13 Uria 實機驗收):第一版實裝判定失敗,已下令回退**(REVERT-PANELS 工單)。失敗點:①方形面板——Uria 明示不要方的,左下原本的 1/4 圓形制不可丟 ②全畫面無對齊系統(左下右下尺寸不一、紀錄欄與儀表板不同寬)③左上銘牌成品像破圖。**本節規格(6.1-6.4)不得再直接施工**;重做需先出視覺樣稿經 Uria 過目才動。守燈人記過:「方形儀表盤」是本規格的錯,不是實作偏差。另:介面縮放裁定改為**固定 85%、移除檔位選項**(6.5 的四檔位設計作廢)。

### 6.1 共同語言

- 深胡桃木面板(`world-deep-walnut #3D2817` 木色族)+ `antique-brass` 黃銅包邊 + 四角黃銅螺絲;圓角 0–2px;像老汽車儀表座/銀行櫃檯儀器盤——**世界觀內的木器,不是懸浮 UI**。
- 數字一律「機械計數窗」:黃銅框小窗 + 乳白底(`world-aged-paper`)+ 墨黑數字(`world-ink-black`)。
- **殼素材(Terra)與活字(HTML)分離**:Terra 只出底板/框/按鈕殼,所有會變的數字文字條全是 HTML 疊層——數值變動不重生圖。

### 6.2 左下儀表板 = 調查員儀表(兩鈕)

- 左端:**棋子頭像黃銅圓窗 = 按鈕①「團隊」**(開團隊狀態檢視),下方小刻牌刻調查員名。
- 中央兩支水平計量槽(黃銅滑槽+乳白背板):**體力**填 `danger #B84C4C`、**理智**填 `info #4A7C9B`,槽端小窗顯數字 `11/12`;瀕死/歸零時槽框轉 `oxblood`,禁發光特效。
- 右端:**黃銅按鈕②「手牌 n」**(開手牌面板)。

### 6.3 右下儀表板 = 帳房儀表(兩鈕)

- 主位:**資源大計數窗**(唯讀)。
- 一排四個**唯讀小計數窗**:牌庫/棄牌/除外/額外(只顯數,不是按鈕)。
- **按鈕①「背包」**(開場上資產/背包檢視,自左側移來)。
- **按鈕②「系統」= 黃銅鑰匙旋鈕**(開系統選單:繼續/設定/規則/回主選單;取代現行 ⚙ 浮鈕,系統不再是孤島)。
- 棄牌/除外/額外的「點開檢視」入口併入**手牌面板頁籤**(手牌|棄牌|除外|額外)——功能不掉、按鈕不增。

### 6.4 左上銘牌 + 戰役紀錄鈕

- 議程/城主與幕/線索改成兩片**掛牆木刻銘牌**(同族木+銅);城主行動點/毀滅 = 黃銅圓表窗,毀滅底色 `oxblood` 小面積;幕與 phase 進度點 = **黃銅座嵌綠玻璃珠**(亮=達成,`success` 色只在珠面)。
- 戰役紀錄開關 = **右緣木質頁籤**(卷宗櫃標籤牌,刻字+箭頭);展開欄體木框 + 舊紙內裡,記錄排版像值勤日誌逐行手記。

### 6.5 系統設定第一項:介面大小

- 檔位制:小 85% / 標準 100% / 大 115% / 特大 130%;黃銅檔位旋鈕 UI,即時預覽。
- 作用對象 = 固定介面層(root CSS 變數統一縮放);地圖層不受影響(自有雙指縮放)。
- 存本地(帳號存檔層上線後隨帳號);特大檔守 §5 總覆蓋率。

### 6.6 按鈕與文字分離合約(全遊戲按鈕通用)

1. 動作鈕(調查/移動/搜尋…)= **獨立圖示鈕**(黃銅框 + 圖示),觸控 ≥44×44px,有下沉態。
2. 說明文字(「調查此地點」「移動到此 · 1 AP」)= 鈕正下方**獨立文字列**,AP 成本併入說明列;禁塞進鈕框互擠。
3. 硬值:說明字 ≥14px(`label-md`)、行高 ≥1.4、字距 ≥0.02em;禁縮字級塞框、禁兩行硬擠,過長裁切加「…」。
4. 文字疊在圖上必有局部襯底(半透暗褐窄條或舊紙小牌),不裸貼。
