## 0. 一句話總覽

調查員 AI 是**規則型隊友**,核心一句:**「人格即資料」**——引擎只有一套「列候選 → 評分 → 模擬前瞻 → 執行」的決策框架,四位 AI 的差異全部來自零件(牌組 / 屬性配點 / 個性權重 / 戰鬥風格),沒有任何「偵探該像偵探」的寫死分支。AI 與真人玩家**完全同管線**:所有行動都組 `IntentMessage` 丟 `resolveIntent`,規則引擎統一裁決。

## 2. 人格即資料 — `InvestigatorAIProfile`(`investigatorAI.ts:34-76`)

| 欄位 | 意義 |
|------|------|
| `name_zh` 等 | 名字(**取名即綁定該模板牌組**) |
| `templateId` | 綁定資料庫 `investigator_templates`(模板名字留白) |
| `freeAttributePoints` | 自由 4 點(規則書 ch6 §2.2:基底 14 + 自由 4 = 18,單項上限 5) |
| `combatStyle`/`specializations` | 起始戰鬥風格(偏重字母對應)+ 熟練第二層專精 |
| **`weights`** | 五項個性權重:`clueFocus` / `combatFocus` / `protectAllies` / `riskTolerance` / `cardPlayAffinity` |
| `sanRetreatPct`/`hpRetreatPct` | SAN/HP 低於此 % 轉保守 |
| `temperature` | 0=永遠最佳解;>0=偶爾選次佳(會犯小錯,像個人) |

## 5. 決策引擎 — 三層

### 5.1 即時評分層 `enumerateCandidates`(`:366-658`)
每行動點列出所有合法候選並評分(成功率 × 個性權重 × 局勢)。候選:調查 / 武器攻擊 / 徒手 / 閃避 / 穩定救援 / 嘲諷 / 出牌 / 移動 / 補給。內建裁定:
- **卡片動作 > 基本動作**(`CARD_ACTION_BONUS=1.6` > 1V):打出的武器一定會開火。
- **整回合三行動價值鏈**(#1):鋪場步繼承未兌現價值。
- **資料驅動目標**:AI「追什麼」來自 `AIObjective`,權重只決定「怎麼追」。

### 5.2 模擬前瞻規劃器 `planTurn`(`:827-873`,正式決策路徑)
- **不定義 combo**:模擬卡序 + beam search,combo 自動浮現。
- 參數:`BEAM=4` / `BRANCH=5` / 深度=min(3,行動點)。
- 模擬器借**真引擎** `resolveIntent`,固定骰 `rng=0.5`(中位 d20≈11)。
- `scoreState`(`:734-779`)= AI 唯一價值觀:敵人活著扣分(目標×1.2)、朝目標靠近加分、線索門檻封頂、自身存活、潛力項(場上資產封頂2件、牌組同軸濃度)。
- `FIRST_STEP_BIAS=0.6`:補償中位骰把高 DC boss 攻擊算成 miss。
- 牌組覺察 `deckAxisPotential`:場上+手上同軸≥2 → 獎勵構築方向。

### 5.3 回合執行 `runInvestigatorAITurn`(`:893-976`)
滾動式:每步 `planTurn` 回最佳第一步 → `resolveIntent` → 重算。`guard<8`、瀕死不動、被駁回就停。運行時狀態:`lastActionType`(防補給連發)+ `cameFromLocationId`(防踱步)。

## 7. 遊戲本體回合驅動(`TestScenarioScreen.tsx`)

- **`stepAITeammate`**(`:586-640`):純計算式,組 allies → `deriveObjective` → `runInvestigatorAITurn` → 寫戰役紀錄+結算六項+自動分配傷害。
- **計時器同時行動**(`:642-674`):每隔 `AI_ACTION_INTERVAL_MS` 讓一位未行動 AI 跑整回合(granularity v0=整回合),非阻塞玩家。
- **競態防護**(Raviel BLOCK 修正):計時器只發訊號,真正跑 AI 在另一支 effect 讀 fresh 閉包,杜絕 lost update。

## 8. 已知 v0 限制 / 改良候選面

1. **escape/survive 目標僅推導未主動評分**——走位型/撐回合型幕,AI 不會主動撤離或拉長存活。
2. **前瞻用固定中位骰**:靠 `FIRST_STEP_BIAS` 補償,屬補丁非機率分布前瞻。
3. **granularity=整回合**:玩家無法在 AI 動作間插入反應。
4. **無玩家↔AI 協同語意**:看得到隊友狀態,但無戰術溝通。
5. **temperature 是唯一擬人雜訊源**:除偶爾選次佳,行為高度確定。
6. **名冊固定四位 INTJ**:人格維度單一,`weights`+配點是目前唯一人格分化軸。
