### Bootstrap 聚合雜湊算法

為讓 64 份忽略檔的資料快取可被日後重算，聚合值固定依下列方法取得：依檔名升冪排序 64 份 `*.json`，逐檔取內容的 SHA-256 十六進位大寫字串，以單一 LF (`0x0A`) 連接，**不在最後加換行**，再對連接後的 UTF-8 bytes 取 SHA-256。因此它不是檔名/內容的直接串接，也不是 Merkle root。

```powershell
$files = Get-ChildItem 'scripts\g1-sandbox\cross-test\.cache\rb-p4d-26071324' -File |
  Sort-Object Name
$hashLines = @($files | ForEach-Object { (Get-FileHash -Algorithm SHA256 $_.FullName).Hash })
$joined = [string]::Join("`n", $hashLines)
$sha = [System.Security.Cryptography.SHA256]::Create()
$aggregate = -join ($sha.ComputeHash([Text.Encoding]::UTF8.GetBytes($joined)) |
  ForEach-Object { $_.ToString('x2') })
```
