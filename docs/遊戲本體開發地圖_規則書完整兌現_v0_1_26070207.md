## Part 2 — 里程碑路線(每站都是可玩增量)

### M1|「一關玩到完整」——雨夜的真相成為規則書級體驗
> 玩家能說:這一關的每個系統都和規則書寫的一樣。
1. **回合流程重設計**(已有裁定):調查員同時/自由順序、短休息個人化——體感最大的一塊
2. **遭遇卡系統點火**:四條觸發途徑接通 + 46 張內容(走 MOD-10 生產線,派工單落檔+校準輪)
3. **神話卡攤開選用**:schema 三欄 + 城主 AI 改「攤開選卡」+ UI 攤開可見(壓力感)
4. 裂嘴女關卡待調清單(6/13 Uria 逐項)+ 全結局敘事文本
5. **64 人交叉測試**(計畫 26070206)→ 調查員 AI 下一輪修正
- 依賴:MOD-10 派工單(backlog 第一優先)|裁定:無新增

### M2|「卡片全規則」——ch3 每種卡玩法都成立
1. deferred 效果碼清完:反應時機窗(對手行動時打出)、混沌袋操縱、tile 系、advance_act
2. 消費 triple 全語意對賬(h06)
3. 法器三時機+過路費結算(s09/s11-13)→ 遭遇卡的「破除軸」才算完整
4. 探索獲卡:discoverable_cards 接入(支柱 6「動態牌組」)
5. 光源物件系統(放置/照明範圍/夜間視線)
- 依賴:M1 遭遇系統(法器與遭遇同軸)|裁定:無

### M3|「打完會變強」——成長與戰役閉環(章節制)
1. XP 結算(過關獎勵+隱藏調查)→ 長休息/整備模式 → 買升級卡/點天賦
2. 天賦樹接入(8 棵內容已在庫等引擎)
3. **玩家存檔層**(3-2,⚖ 存檔歸屬裁定後動工)
4. 章節→戰役串連:結局分歧影響下一章(flag 已有,串連 UI/流程缺)
5. 團隊精神接入(33 個在庫)
- 依賴:3-2 裁定|這站做完 = **「戰役模式」誕生**

### M4|「世界變大」——內容規模化(生產線挑大樑)
1. 第二個戰役全流程走 Story-to-Stage(順帶把 pipeline 派工單化,MOD-06/07/08)
2. 怪物家族擴充(13 family 藍圖,MOD-03 線)
3. 鍛造系統:引擎(h07)+ MOD-09 生產線從零建
4. 遭遇卡池/神話卡池按章節梯度擴充
- 特性:主 session 只做引擎,內容全走 Agent 化生產線(本日基建的收成站)

### M5|「給真人玩」——玩家體驗與門面
1. 大廳四席任選(工作一)+ 泛用 AI 人格
2. 檢定刻度正式修法(設計債清償,⚖ 修法清單已有)
3. s06 文法全面過閘(所有引擎敘事行)、教學流程、UI/演出打磨
4. ⚖ **多人範圍裁定**:單機+AI 隊友為正式形態,或做真人連線(架構已多人-ready,但連線層是獨立工程)
- 這站的排序可以和 M3/M4 交錯,依你想先給誰玩

### M6|「對賬驗收」——規則書全綠
1. 引擎對照清單 v2 全面重審(逐條規則書承諾 × 原始碼)
2. 全戰役 dry run(選人→戰役→跨章成長→結局)+ 平衡輪(64 人勝率矩陣複跑)
3. 殘項清零或立正式設計債文件

## Part 4 — 執行原則

- **每站結束 = 一次可玩驗收**:你上正式站玩,不是看我的報告。
- **引擎歸主 session,內容歸生產線**:M1 起每站的內容需求直接開派工單,低階模型操作。
- **凍結紀律**:AI 測試期凍結關卡與城主;平衡調整只在 M6 平衡輪集中做,不散裝。
- 底冊(引擎對照清單)每站更新一版,是唯一的「還剩多少」量尺。
