# 四席人影位置／光影校準

本目錄是 ART-CALIBRATION 的下一個校準步驟，僅供比較四個座位的人影位置、透視、曝光、rim light、接觸關係與接縫。

- 每席 2 個候選，共 8 個。
- 背景基準固定為上一輪 `A-study-v1.png`。
- 棋子沿用上一輪 Uria PASS 素材。
- 打擊字卡沿用上一輪 WARN 素材，不代表可上線版本。
- 本目錄不接 runtime，不是 24 席量產素材。

## 交付候選

| 座位 | 候選 | 校準差異 |
|---|---|---|
| 1 左側窗邊 | `seat-1A-fullscene.png` | 無帽、微前傾 |
| 1 左側窗邊 | `seat-1B-fullscene.png` | 軟呢帽、直坐 |
| 2 後方中央 | `seat-2C-fullscene.png` | 寬帽沿遮臉、低頭 |
| 2 後方中央 | `seat-2D-fullscene.png` | 短髮背向、直坐 |
| 3 右側火爐 | `seat-3A-fullscene.png` | 工作者、背向桌面 |
| 3 右側火爐 | `seat-3B-fullscene.png` | 表演者、側坐交腿 |
| 4 右下前景 | `seat-4A-fullscene.png` | 私家偵探、前傾看圖 |
| 4 右下前景 | `seat-4B-fullscene.png` | 學者、直坐留出地圖 |

開啟 `index.html` 可逐席並排比較，並在同頁看到上一輪 PASS 棋子與 WARN 字卡。

這八張是完整情境校準圖，不是可上線透明覆蓋層。其用途是先讓 Uria 選定每席的姿勢、比例與局部光影；選定後才依同一方向製作可換裝的透明 WebP 覆蓋層。
